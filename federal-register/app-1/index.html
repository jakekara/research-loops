Should I read this?

You have more documents than you can read. Hand over the pile and the standard you read by, and get one judgment per document — kept or cut, scored, with the reason and the phrase it turned on. The cuts stay on screen. That is where you find out whether your standard says what you meant.

Workspace IDusually blank

This page has no server. Your key is held in this browser tab and sent only to api.anthropic.com. The only other origin it can reach is the full-text proxy, fr-fulltext…workers.dev, which receives a document number and a date and nothing else. There is no backend, so there is nowhere for anything to be stored even by accident. The page loads no external scripts, fonts, or analytics; a Content-Security-Policy in the source blocks them. Leave it that way. Get a key at console.anthropic.com and set a monthly spend limit.

Leave Workspace ID blank unless the API tells you to fill it. Most keys are scoped to one workspace when you create them, so the call already knows where it belongs. Identity-linked keys are not. If you see "anthropic-workspace-id is required", paste the wrkspc_… id here, or make a plain workspace-scoped key in the Console instead and leave this empty.

Running this file

Double-click it and it works. If calls fail with a network or CORS error, your browser is refusing requests from a file:// page. Open a terminal in this folder and run python3 -m http.server 8000, then visit localhost:8000. Same file, real origin. It is one static file with no build step and no dependencies.

Where the pile comes from

Search federalregister.gov yourself, narrow it until the result set is one you would defend, then use the CSV link at the top of the results page. Do that part by hand. If this tool ran the search for you, you would not know what was in the pile before the model started cutting it — and the cut list is the part worth reading.

Before you publish anything from this

This screens. It does not verify, it does not call anyone, and it is confidently wrong on a regular basis. A kept document is a lead. Open it, read the passage yourself, and report it out. A cut document is an argument you are allowed to lose.
