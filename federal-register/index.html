Workspace IDusually blank

This page has no server. Your key is held in this browser tab and sent only to api.anthropic.com. Searches go only to www.federalregister.gov. Nothing is logged, stored, or transmitted anywhere else — and because there is no backend, there is nowhere for it to be stored even by accident. The page loads no external scripts, fonts, or analytics; a Content-Security-Policy in the source blocks them. Leave it that way. Get a key at console.anthropic.com and set a monthly spend limit.

Leave Workspace ID blank unless the API tells you to fill it. Most keys are scoped to one workspace when you create them, so the call already knows where it belongs. Identity-linked keys — the kind minted automatically for a person rather than created in the Console — are not, so they need to be told. If you see "anthropic-workspace-id is required", paste the wrkspc_… id here, or make a plain workspace-scoped key in the Console instead and leave this empty.

Running this file

Double-click it and it works. If calls fail with a network or CORS error, your browser is refusing requests from a file:// page. Open a terminal in this folder and run python3 -m http.server 8000, then visit localhost:8000. Same file, real origin. You can also drop it on GitHub Pages, Netlify, or Cloudflare Pages — it is one static file with no build step and no dependencies.

Before you publish anything from this

The loop finds documents and says why it thinks they matter. It does not verify, it does not call anyone, and it is confidently wrong on a regular basis. Everything it produces is a lead. Open the document, read the passage yourself, and report it out.
